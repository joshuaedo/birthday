# Is Today Joshua Edo's Birthday?

Having a birthday at the year's end is the perfect excuse for a personal year-in-review. So, let's do that. This site is a *special one*, live only once a year on November 28th—my birthday.

## About Me

I'm Joshua Edo, a web developer focused on creating functional and visually engaging digital experiences. 

## Technologies Used

The website uses the following technologies:

1. **React**: Manages the website's dynamic and interactive features.
2. **Vite**: A fast build tool that streamlines development and improves performance.
3. **TypeScript**: Adds static typing to enhance code quality and reduce bugs.
4. **Framer Motion**: Adds animations and transitions for a more fluid user experience.
5. **GSAP**: A JavaScript animation library used to create visual effects.
6. **React Router DOM**: Handles client-side routing for seamless navigation.
7. **TanStack React Query**: Manages server state and data-fetching efficiently.
8. **TailwindCSS**: A utility-first CSS framework for designing responsive and modern UIs.
9. **TailwindCSS Animate**: Extends TailwindCSS with predefined animations.
10. **Zod**: A schema declaration and validation library for TypeScript.
11. **Lucide React**: Provides customizable icons for a modern look.
12. **React Fast Marquee**: Adds scrolling marquee animations.
13. **Radix UI**: Implements accessible UI primitives for progress bars, hover cards, and switches.
14. **Class Variance Authority (CVA)**: Manages TailwindCSS classes with composable variants.
15. **Clsx**: A utility for conditional className management.
16. **React Animated Cursor**: Adds customizable animated cursors for an enhanced user experience.
17. **Unplugin Fonts**: Simplifies font management in the project.

**Development Tools:**

- **TypeScript**: Ensures type safety during development.
- **ESLint**: Enforces coding standards and best practices.
- **Turbo**: Optimizes build processes for faster iteration.
- **Tailwind Merge**: Enables merging of TailwindCSS classes for dynamic styling.
- **PostCSS & Autoprefixer**: Ensures CSS compatibility across different browsers.

## Getting Started

To run the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/birthday-v2.git
   ```
2. Navigate to the project directory:
   ```bash
   cd birthday-v2
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Visit the site at:
   ```
   http://localhost:3008 
    ```
